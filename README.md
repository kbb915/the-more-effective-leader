# The More Effective Leader

A responsive, static website for The More Effective Leader, an eight-week online development experience for leaders who want to function more effectively in difficult situations. Deploy this repository to Vercel with the Other framework preset and the repository root as the output directory. No build step or dependencies are required.

## Preview

Run `python3 -m http.server 8765` in this folder and visit http://localhost:8765.

## Before opening enrollment

Tuition is $1,150 individual, $950 per person for groups of three or more, and $850 per person for nonprofits, with unlimited repeat attendance at no additional cost after the first attendance. Confirm program dates and the registration/contact destination. The page accurately shows enrollment as coming soon until those details are provided. No submissions are collected.
